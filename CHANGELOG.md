# Changelog

## 2.0.0 — Violet Pulsar · First Pulse — 2026-10-01

- Rebuilt the Bootstrap task list as the Violet Pulsar mission-control interface.
- Added complete English and German localization.
- Added persistent theme, density and reduced-motion settings.
- Added priorities, deadlines, overdue detection, search, filters and sorting.
- Added fast mission completion and improved account-scoped authorization.
- Repaired registration by removing the unusable email-confirmation requirement.
- Moved the SQLite database to the operating system's application-data directory.
- Added automatic legacy database import and schema migration.
- Removed committed databases, build output and unused frontend vendor files.
- Added self-contained Windows, Linux and macOS release builds with diagnostics.
